# Moon Curses → Fansly (Chrome extension)

Sends the final speech-to-text results from Moon Curses to your Fansly live chat.
Works on `fansly.com/creator/streaming` and `fansly.com/live/runalewdie`.

## Install
1. Chrome → `chrome://extensions` → turn on **Developer mode**.
2. **Load unpacked** → pick this folder (`extensions/fansly-chrome`).
3. In Moon Curses, open Integrations → Fansly and turn on **Enable**.

Click the extension icon to see the connection status, change the port (default 3030),
pick the chat box manually, or send a test message. Reload the extension and the Fansly tab after updating.
